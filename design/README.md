# Design

- `../DESIGN.md`: cores, fontes, componentes e regras da Capi. É a fonte da verdade do visual.
- `telas/`: as telas de referência exportadas do Claude Design (canvas "Capi — telas do app"). Servem para olhar e copiar medidas, não são código do app. Elas usam o runtime do Claude Design (`support.js`), então abrem melhor pelo canvas.
- `capi/`: a mascote. `capi-*.png` são as poses de uso, `dia-*.png` são as figurinhas da Capi do dia e `capi-icone-original.png` é o ícone em alta resolução (exportar sem as bordas arredondadas para o ícone do PWA).
