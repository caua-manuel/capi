# Rótulos de triagem

| Papel nas skills | Rótulo neste repositório | Significado |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | O dono precisa avaliar |
| `needs-info` | `needs-info` | Falta informação (por exemplo, o texto real da fatura) |
| `ready-for-agent` | `ready-for-agent` | Bem definida, pronta para o Claude implementar |
| `ready-for-human` | `ready-for-human` | O dono precisa fazer à mão |
| `wontfix` | `wontfix` | Não será feita |

Além desses: `em-andamento` enquanto alguém trabalha na issue. Uma issue terminada é **fechada**.
