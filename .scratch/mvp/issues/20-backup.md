# 20: Backup com senha opcional

**O que construir:** O Usuário exporta um arquivo com todos os dados, pode protegê-lo com senha e restaura em outro aparelho.

**Bloqueado por:** 06 (Cadastro de Fixos), 08 (Metas com escada, Aporte e duas datas)

**Modelo:** Sonnet · Fase C

**Status:** ready-for-agent

- [ ] Exportar gera um arquivo com todas as entidades
- [ ] Com senha, o arquivo fica criptografado e só abre com a mesma senha
- [ ] Restaurar substitui os dados atuais após confirmação
- [ ] Senha errada mostra erro claro e não apaga nada
